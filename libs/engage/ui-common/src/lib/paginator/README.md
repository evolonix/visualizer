# Paginator

The paginator component provides page buttons and an items per page selector. It should be added to the foot of a table.

Here are some example layouts and behaviors of the paginator.

![First page selected](https://user-images.githubusercontent.com/1501490/186968924-7dffc546-6da2-49c8-ab70-5e225f080a00.png)

When the first page is selected, the first and previous page arrow buttons are disabled and an ellipsis is included in the seven page buttons displayed.

![Middle page selected](https://user-images.githubusercontent.com/1501490/186968927-5799d362-2dd2-4ff0-84e0-1a8384580964.png)

When a middle page is selected, two sets of ellipses are included in the seven page buttons displayed. Both sets of arrow buttons are enabled.

![Last page selected](https://user-images.githubusercontent.com/1501490/186968930-eb7d1e23-cfed-488e-a8ee-5427ecb3ade4.png)

When the last page is selected, the last and next page arrow buttons are disabled and an ellipsis is included in the seven page buttons displayed.

![Small screen layout](https://user-images.githubusercontent.com/1501490/186968931-af289375-e399-46dd-bbd4-32a04543f8b3.png)

When the resolution is smaller than the large resolution from the [grid design](https://www.figma.com/file/Mk4T9KHbxfA6o0pftnC9MI/AP-Foundations?node-id=4%3A313), only two page buttons are displayed. There is no ellipsis included and the sets of arrow buttons function according to what page is selected, as described above.
