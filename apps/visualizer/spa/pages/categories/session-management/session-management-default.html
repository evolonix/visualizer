Security

Web App

These settings will apply to all users accessing the system through a traditional web or mobile web browser.

Web App Session Cookie Mode

Inactivity Time-Out

How long a session cookie will remain active after it has been idle. (max. 100 days, default = 14 days)

Log In Time-Out

Regardless of how long the user is active, they will have to re-login after this period of time. (max. 365 days, default = 30 days)
