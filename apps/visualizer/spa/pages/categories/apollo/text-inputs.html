Caution On Using

Never use the disabled attribute, only use readonly on inputs. aria-disabled may still hide the information from screen readers.

And if you do not need to convey information with a field, consider removing it from the page over marking it as readonly. Readonly fields should be reserved for cases like editing where some fields may no longer be editable but the information is still relevant to the user.
