Note: We use `aria-hidden=true` on the description so it that doesn't read as part of the label but after the short pause, so it's more skippable. Animals (Disabled)

Note: This should always be avoided. There is no way to make the radio buttons readable to screen readers; the `readonly` attribute does not apply for radios in Tailwind and I do not believe it reads out correctly to screen readers either. Recommended is to simply have plain text that reads out the selected and potential values if needed.
